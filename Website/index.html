About

What is FreeSabers?

Open Source Alternative

FreeSabers is a free, open-source Beat Saber Quest mod that lets you use custom saber models in-game. No paywalls, no subscriptions, no locked features — everything is free forever under the MIT license.

ReeSabers Compatible

Uses the same saber format as ReeSabers. Download sabers from the same community sources, drop them in your Quest, and play. No conversion needed — it just works.

Community Driven

Built by Beat Saber modders for modders. The code is on GitHub — contribute features, fix bugs, add saber formats, or help with documentation. No corporate ownership, no hidden agendas.

Features

Everything You Need

Custom Saber Models

Load .saber files with custom models, trails, shaders, and sounds. Supports the full ReeSabers format specification.

In-Game Menu

Full BMBF/ModSettings UI integration. Browse, preview, and switch sabers without leaving the game. Search and filter your collection.

Trail Customization

Per-saber trail colors, widths, textures, and animation speeds. Create unique visual signatures for every saber in your library.

Multiplayer Safe

Designed for multiplayer compatibility. Sabers sync correctly in co-op and party modes. No desync issues, no crashes.

Performance Optimized

Built for Quest's mobile GPU. Efficient rendering, minimal memory footprint, and zero frame drops even with complex saber models.

Auto-Updates

Optional update notifications via GitHub Releases. One-tap updates keep you on the latest version with new features and fixes.

Installation

Get Started in Minutes

# 1. Install BMBF on your Quest # 2. Open BMBF web interface # 3. Go to "Mods" → "Online" → Search "FreeSabers" # 4. Click "Install" → "Sync to Beat Saber" # Or use the direct download link: https://github.com/donoigabriel6-a11y/FreeSabers/releases/latest/download/FreeSabers.qmod
# 1. Download latest .qmod from GitHub Releases https://github.com/donoigabriel6-a11y/FreeSabers/releases # 2. Connect Quest via USB, enable Developer Mode # 3. Open SideQuest → "Install APK from file" → Select .qmod # 4. Launch Beat Saber → Mods menu → Enable FreeSabers
# Clone and build from source git clone https://github.com/donoigabriel6-a11y/FreeSabers.git cd FreeSabers ./gradlew buildQuest # Output: build/outputs/FreeSabers.qmod # Requires: Android SDK, NDK, Quest Developer Mode
1

Install Mod Loader

Set up BMBF or use SideQuest to install the .qmod file on your Quest headset.

2

Enable FreeSabers

Launch Beat Saber, open the Mods menu, and toggle FreeSabers on. Restart if prompted.

3

Add Sabers

Download .saber files from the community, place them in /sdcard/ModData/com.beatgames.beatsaber/Mods/FreeSabers/Sabers/

4

Play!

Open the FreeSabers in-game menu, select your saber, and start slicing blocks with style.
